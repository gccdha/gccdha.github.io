Knights

A while ago, I was watching this Numberphile video about pieces aranged on an infinite chessboard. I had a few variations on this concept that I wanted to see so I created a small program to generate them. I mainly was interested in how space filling curves other than a spiral would effect the result, but also added in functionality for custom pieces. A few weeks later I was looking for a project to tinker with WASM and this seemed like a good candidate.
